# KonoLabs

**Hardware and software engineering, under one roof.**

KonoLabs is a small engineering lab. We design electronic products and write the software that
runs on them: the circuit board, the firmware on the chip, the backend behind it, and the
website or dashboard on top. One team from the first sketch to the finished product — no
hand-offs between five different contractors.

## What we build

- **Boards** — schematics, PCB layout and a first working sample on your desk, plus the files
  the factory needs to build it.
- **Firmware** — the code living on the chip itself: fast to start, built to run for years.
- **Software** — the services next to the device that collect, store and pass on what it
  reports, plus the websites and dashboards people actually use.

### Fusible

Hardware and firmware usually live in separate worlds, and mistakes only show up on the bench.
Fusible puts them in a single contract: `fusible.yml` ties the circuit, the chip and the
firmware together, and the build refuses to generate code for a board that does not pass its
electrical rules. Fail-closed by design — a broken circuit never reaches production.

```sh
cargo install --path .
fusible init --name sensor-node
fusible check   # ✅ circuit validated (fuse intact) — or the fuse blows
```

Full docs, exit codes and the roadmap live in the
[Fusible README](https://github.com/KonoLabs/Fusible#readme).

## Tools we work with

Boards designed in KiCad or tscircuit. Firmware in C, C++ and Rust on ESP32, STM32, Luckfox and
friends. Backend and tooling in Go, Rust and TypeScript. Websites in SvelteKit.
